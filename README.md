## 1. css 작성법 3가지

- 작성법 3가지 중에 누가 최종적으로 적용되는가? (누가 힘이 쎈가?)

### 1.1 inline 방식

- html 태그에 직접 작성해 주는 방식

### 1.2 link 방식

- file 로 작성해서 link 하는 방식 (경로/파일명.css)
- css 폴더/common.css

### 1.3 @import 방식

- css 파일에서 또 다른 css 파일을 참조하는 방식
